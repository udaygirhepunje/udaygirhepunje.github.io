I developed PullPanda as a GitHub application using the Probot framework to automate pull request code reviews.

The agent evaluates diffs against team conventions and posts actionable, contextual feedback. It has reviewed more than 5,150 pull requests across 26+ repositories, cutting false positive review comments by 50% through tailored prompt refinement.
